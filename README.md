# FisioSis
Modelos Interactivos para la Enseñanza de Fisiología 🫀🧠🫁
Bienvenido a FisioSis, un espacio dedicado al desarrollo de modelos cuantitativos, simulaciones interactivas y recursos computacionales para facilitar la enseñanza y el aprendizaje de la fisiología.
📌 Visión General
La fisiología moderna requiere ir más allá de los diagramas estáticos. Este repositorio ofrece un conjunto de herramientas y modelos dinámicos diseñados para transformar conceptos fisiológicos abstractos —como la dinámica de fluidos en el sistema cardiovascular, la electrofisiología neuronal o el intercambio gaseoso pulmonar— en experiencias de aprendizaje intuitivas y manipulables.
🚀 Objetivos
Visualización Dinámica: Traducir ecuaciones y principios fisiológicos complejos en simulaciones gráficas y comprensibles.
Recursos Educativos Abiertos (REA): Proveer material de libre acceso para docentes, estudiantes e investigadores.
Interactividad: Permitir la modificación de variables y parámetros para observar respuestas fisiológicas en tiempo real.
